# Roadmap

This repository stays MVP-first: deterministic, local, and easy to run. Future upgrades should preserve that baseline.

## Near-term

- Add a weekly review workflow that summarizes generated outputs.
- Add dedicated workflows for AI overseas business, AI fiction/IP experiments, and Chinese memory palace content.
- Add a simple local index of generated files.
- Add more sample inputs for real publishing rhythms.

## Mid-term

- Add optional LLM adapters with environment-variable configuration and offline fallback.
- Add Markdown-to-PDF export support as an optional dependency.
- Add CRM-style follow-up tracking for alumni/company visits.
- Add GitHub Actions artifact upload for scheduled sample runs.

## Guardrails

- Faith workflows should remain study aids and should not distribute copyrighted Bible translations in bulk.
- Family logs and business notes should remain private by default.
- Publication workflows should always include a manual review step for facts, privacy, and permissions.
